# Typescript Trivia

This is a small example project to be used within a workshop about the basics of TypeScript.
It's powered by [TypeScript](https://www.typescriptlang.org/), [Vite](https://vitejs.dev/) and [Onyx](https://onyx.schwarz/).

## Setup

In order to use this project you'll need to have [Node JS](https://nodejs.org/en/download) >=24 installed on your system.
Afterwards you can clone this repo and install the required dependencies:

```bash
npm install
```

## Running the application

To start the example app run the following command in a terminal at the root of this repo:

```bash
npm run dev
```

This will start the dev server and open the application at http://localhost:5173/ in your browser.
